# Frankendom test player

Run `./run-latest.sh` on a Mac with Node.js. It pins one reviewed game commit, installs dependencies on first use, builds locally, and plays three Pitborn fights on Easy. The default uses tactical policy with **limited observation**: delayed opponent events and rounded, delayed distance. It drives real Playwright keyboard input and saves fight JSON and optional WebM under `game/artifacts/combat/player-bot/`. Use `./run-latest.sh --opponents=all --fights=3` for all nine playable Easy opponents, `--headed` to watch, `--smoke` for one fight, `--no-video` for faster measurement, or `--observation=debug` for exact-state diagnostics. It exits nonzero unless at least two of three fights are wins per opponent and each fight has at most 20% Heavy attack starts.

The tactical bot uses range-aware slash and thrust, delayed directional guard, confirmed counters, stamina recovery, and a lateral roll after an observed charged overhead. In the full Easy browser batch it won **26/27 with limited observation**: Goblin was 2/3, every other opponent 3/3, and every fight stayed at or below 18.8% Heavy. The same unchanged policy won 27/27 in the earlier exact-debug batch. All inputs released with no runner errors. Receipts include tell-to-defence outcomes; three seeds per opponent remain a small sample, and telemetry does not prove human cue readability. `./archive/run-heavy-only.sh` explicitly runs the old charged policy. `./run-baseline.sh` prints a migration notice.
