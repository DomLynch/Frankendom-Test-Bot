# Frankendom test player

The current test candidate is pinned to [Frankendom commit `b5bce004`](https://github.com/DomLynch/RPG-game/commit/b5bce00418319199665a8736d22d7f120770c5fe) on draft PR #632. Run `./run-baseline.sh` on a Mac with Node.js; it installs the project packages and Playwright Chromium on first use. Pass `--strategy=charged|counter`, `--opponents=all`, `--seed=731`, `--fights=3`, `--no-video`, or `--out=artifacts/combat/my-run` through to the runner. It builds a local game checkout, drives Easy fights through real keyboard input, and saves fight JSON and optional WebM under that checkout's `artifacts/combat/` directory.

This revision adds spacing, wall and initiative metrics. One charged-mode browser fight each against Pitborn and Veteran won on the prior trunk; the counter strategy's last three-fight comparison won 0/3 despite landing 8/8 stabs and avoiding wall lashes. **The 70% per-opponent browser target remains unproven.** Use this pinned candidate to test the bot and recordings; no production game state is changed.
