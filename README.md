# Frankendom test player

The current test candidate is pinned to [Frankendom commit `22ca94ff`](https://github.com/DomLynch/RPG-game/commit/22ca94ff0d4bae9125831e45b934cd3564c5acee) on draft PR #632. Run `./run-baseline.sh` on a Mac with Node.js; it installs the project packages and Playwright Chromium on first use. Pass `--strategy=charged|counter`, `--observation=debug|limited`, `--opponents=all`, `--seed=731`, `--fights=3`, `--no-video`, or `--out=artifacts/combat/my-run` through to the runner. It builds a local game checkout, drives Easy fights through real keyboard input, and saves fight JSON and optional WebM under that checkout's `artifacts/combat/` directory.

The charged policy won 26/27 browser fights across nine playable Easy opponents: Pitborn 2/3 and each other opponent 3/3. A separate Pitborn batch won 7/10. The owner's batch pass bar is two-thirds per opponent; three fights each is a small sample, so the receipt records every result. This revision also saves intention/input/outcome logs, spacing and wall metrics, and short clips of teachable moments. Clips are silent; limited-observation mode and the counter strategy are diagnostic, not part of the charged-policy pass claim. No production game state is changed.
