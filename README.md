# Frankendom test player

Run `./run-latest.sh` on a Mac with Node.js. It pins the game to [commit `9483f894`](https://github.com/DomLynch/RPG-game/commit/9483f894d19fdd5b34ae41463bb949770fd9b306), installs dependencies on first use, builds locally, and plays three Pitborn fights on Easy. It drives real Playwright keyboard input and saves fight JSON and optional WebM under `game/artifacts/combat/player-bot/`. Use `./run-latest.sh --opponents=all --fights=3` for all nine playable Easy opponents, `--headed` to watch, `--smoke` for one fight, or `--no-video` for faster measurement. It exits nonzero unless at least two of three fights are wins per opponent and each fight has at most 20% Heavy attack starts.

The tactical bot uses range-aware slash and thrust, delayed directional guard, confirmed counters, stamina recovery, and a lateral roll after an observed charged overhead. The unchanged policy won 27/27 browser fights across nine Easy opponents at three seeds each, with no runner errors or held inputs; the highest per-fight Heavy share was 16.7%. This revision adds a tell-to-defence outcome report and the matched debug/limited assessment. Its exact debug observations measure mechanics, not human cue readability, and three seeds per opponent remain a small sample. `./archive/run-heavy-only.sh` explicitly runs the old charged policy. `./run-baseline.sh` prints a migration notice.
